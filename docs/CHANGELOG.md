# CHANGELOG

## [1.0.0]  — Sprint 8 (Final Release)

### Добавлено
- **CLI с флагами**: `-o`, `-S`, `-c`, `-E`, `-v`, `-O`, `--ast`, `--ir`, `-Wall`, `-Werror`, `-Wno`, `--error-format`, `--color`, `--max-errors`, `--target`, `--format`, `--stats`, `--show-types`
- **Цветной вывод ошибок**: human-readable, JSON, GCC-совместимые форматы
- **Warning system**: `-Wall`, `-Werror`, `-Wno=<code>` (коды W001-W003)
- **JSON формат ошибок**: `--error-format=json`
- **Компиляция в объектный файл**: `-c`
- **Препроцессор**: `-E` (вывод токенов)
- **Множественные файлы**: `compiler main.src utils.src -o program`
- **Man-страница**: `man mikrocompiler` (после `make install-man`)
- **Расширенный тестовый набор**: 80+ финальных тестов в `tests/final/`
- **Документация**: `docs/language_spec.md`, `docs/developer.md`, `docs/tutorial.md`

### Исправлено
- **Segfault в массивах**: исправлено выравнивание 8-байтовых переменных в стеке (`AllocateVar`, `collectAllocations`)
- **Перекрытие переменных**: 8-байтовые переменные выделяются первыми с правильным выравниванием
- **Конфликт меток**: метки IR теперь уникальны для каждой функции
- **Флаг `-o`**: теперь работает при любом порядке аргументов
- **`_start` конфликт**: не генерируется при использовании libc

### Известные ограничения
- Массивы с 7+ элементами в цикле `for` могут давать неверный результат
- Присваивание полям структур (`p.x = 10`) не поддерживается парсером
- Рекурсивные функции с несколькими вызовами разных функций могут давать неверный результат

## [0.7.0]  — Sprint 7 (Arrays, Extern, Optimizations)

### Добавлено
- **Поддержка массивов**: `int arr[N]`, `arr[i]`, инициализаторы `{1, 2, 3}`
- **Выделение через malloc/free**: автоматическое для локальных массивов
- **Проверка malloc на NULL**: вызов `abort()` при ошибке выделения
- **Внешние функции**: `extern` объявления, вызов `printf`, `malloc`, `free`, `abort`
- **IR оптимизатор**: свёртка констант, алгебраические упрощения, dead code elimination
- **GEP инструкция**: `GetElementPointer` для вычисления адресов элементов массива
- **ArrayGenerator**: генерация кода для операций с массивами
- **ExternalCallGenerator**: вызовы внешних функций с соблюдением ABI
- **PeepholeOptimizer**: 9 оптимизационных проходов

## [0.6.0]  — Sprint 6 (Control Flow)

### Добавлено
- **ControlFlowGenerator**: условные и безусловные переходы
- **Short-circuit evaluation**: `&&` и `||` с минимальным вычислением
- **ExpressionGenerator**: арифметические, логические операции, сравнения
- **LabelManager**: уникальные метки для ассемблерного кода
- **For/While циклы**: полная поддержка с правильными метками
- **If-else**: вложенные условные конструкции
- **Logical operators**: `&&`, `||`, `!` с short-circuit

---

## [0.5.0]  — Sprint 5 (x86-64 Code Generation)

### Добавлено
- **x86Generator**: генерация ассемблера x86-64 (NASM)
- **StackFrame**: управление стековыми кадрами
- **RegisterAllocator**: простой аллокатор регистров
- **ABIInfo**: System V AMD64 ABI (параметры в rdi, rsi, rdx, rcx, r8, r9)
- **Runtime library**: `print_int`, `print_string`, `read_int`, `exit`
- **Function prologue/epilogue**: `push rbp; mov rbp, rsp; sub rsp, N`
- **AssemblyOptimizer**: peephole оптимизации ассемблера

## [0.4.0]  — Sprint 4 (IR)

### Добавлено
- **IR инструкции**: ADD, SUB, MUL, DIV, MOD, CMP, JUMP, CALL, RETURN и др.
- **BasicBlock**: базовые блоки с предшественниками/последователями
- **Control Flow Graph (CFG)**: построение и обход
- **PHI узлы**: для SSA формы
- **Def-Use цепочки**: анализ использований переменных
- **IR принтеры**: text, DOT (Graphviz), JSON
- **Статистика IR**: количество инструкций, блоков, temporaries

## [0.3.0] — Sprint 3 (Semantic Analysis)

### Добавлено
- **SemanticAnalyzer**: проверка типов, областей видимости
- **SymbolTable**: иерархическая таблица символов (global, function, block)
- **TypeSystem**: int, float, bool, void, string, struct, array, pointer
- **ErrorCollector**: коды ошибок E001-E017 с подробными сообщениями
- **Декорированный AST**: аннотации типов на выражениях
- **Проверка возврата**: все пути в не-void функции должны возвращать значение
- **Проверка аргументов**: количество и типы при вызове функций

- **AST узлы**: Program, FunctionDecl, VarDecl, IfStmt, WhileStmt, ForStmt, BinaryExpr, CallExpr и др.

## [0.1.0] — Sprint 1 (Lexer)

### Добавлено
- **Scanner**: лексический анализатор (токенизация)
- **Токены**: 50+ типов (ключевые слова, операторы, разделители, литералы)
