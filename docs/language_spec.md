# Спецификация языка MiniLang v1.0

## 1. Лексическая структура

### 1.1 Алфавит

Исходный код использует кодировку UTF-8. Допустимые символы:
- Буквы: `a-z`, `A-Z`
- Цифры: `0-9`
- Специальные символы: `+-*/%=!<>&|(){}[];:.,_"'\``
- Пробельные символы: пробел, табуляция (`\t`), перевод строки (`\n`), возврат каретки (`\r`)

### 1.2 Комментарии

```c
// Однострочный комментарий (до конца строки)

/* Многострочный комментарий
   может занимать несколько строк */

/* Вложенные /* комментарии */ поддерживаются */
```

### 1.3 Идентификаторы

**Правила:**
- Начинаются с буквы или подчёркивания
- Содержат буквы, цифры, подчёркивания
- Максимальная длина: 255 символов
- Регистрозависимые (`Foo` ≠ `foo`)

**Примеры:**
```
x, counter, MAX_SIZE, foo_bar, snake_case, camelCase, PascalCase, _private
```

### 1.4 Ключевые слова

```
if, else, while, for, int, float, bool, string, void, struct, fn, extern, return, true, false
```

Ключевые слова зарезервированы и не могут использоваться как идентификаторы.

### 1.5 Литералы

#### Целые числа (`int`)
- 32-битные знаковые целые
- Диапазон: [-2³¹, 2³¹-1] = [-2_147_483_648, 2_147_483_647]
- Формат: десятичные цифры, опциональный знак `-`
```
42, 0, -10, 2147483647, -2147483648
```

#### Числа с плавающей точкой (`float`)
- 64-битные (double precision)
- Формат: `цифры.цифры`, опциональный знак `-`
```
3.14, -0.5, 1.0, 0.001, -273.15
```

#### Булевы значения (`bool`)
```
true, false
```

#### Строки (`string`)
- Заключены в двойные кавычки `"`
- Поддерживают escape-последовательности:
  - `\n` — перевод строки
  - `\t` — табуляция
  - `\"` — двойная кавычка
  - `\\` — обратный слеш
  - `\0` — нулевой символ
```
"Hello, World!", "", "строка с \"кавычками\"", "line1\nline2"
```

### 1.6 Операторы и разделители

| Категория | Токены |
|-----------|--------|
| Арифметические | `+`, `-`, `*`, `/`, `%` |
| Сравнения | `==`, `!=`, `<`, `<=`, `>`, `>=` |
| Логические | `&&`, `||`, `!` |
| Присваивания | `=`, `+=`, `-=`, `*=`, `/=` |
| Разделители | `(`, `)`, `{`, `}`, `[`, `]`, `;`, `,`, `.` |
| Указатели | `->`, `*` |

## 2. Синтаксис (формальная грамматика)

### 2.1 Обозначения

- `::=` — определение правила
- `|` — альтернатива
- `{ }` — повторение 0 или более раз
- `[ ]` — опционально
- `( )` — группировка

### 2.2 Программа

```
Program        ::= { Declaration }

Declaration    ::= FunctionDecl | StructDecl | VarDecl | ExternDecl
```

### 2.3 Объявления

```
FunctionDecl   ::= Type "fn" Identifier "(" [ Parameters ] ")" ["->" Type] Block
                | Type Identifier "(" [ Parameters ] ")" Block

ExternDecl     ::= "extern" Type Identifier "(" [ Parameters ] ")" ";"

StructDecl     ::= "struct" Identifier "{" { VarDecl } "}" ";"

VarDecl        ::= Type Identifier [ "=" Expression ] ";"
                | Type Identifier "[" Expression "]" [ "=" ArrayLiteral ] ";"

Parameters     ::= Parameter { "," Parameter }

Parameter      ::= Type Identifier [ "[]" ]
```

### 2.4 Инструкции

```
Statement      ::= Block | IfStmt | WhileStmt | ForStmt | ReturnStmt
                | ExprStmt | VarDecl

Block          ::= "{" { Statement } "}"

IfStmt         ::= "if" "(" Expression ")" Statement [ "else" Statement ]

WhileStmt      ::= "while" "(" Expression ")" Statement

ForStmt        ::= "for" "(" [ ExprStmt | VarDecl ] ";" [ Expression ] ";" [ Expression ] ")" Statement

ReturnStmt     ::= "return" [ Expression ] ";"

ExprStmt       ::= Expression ";"
```

### 2.5 Выражения

```
Expression     ::= Assignment

Assignment     ::= LogicalOr { ("=" | "+=" | "-=" | "*=" | "/=") Assignment }

LogicalOr      ::= LogicalAnd { "||" LogicalAnd }

LogicalAnd     ::= Equality { "&&" Equality }

Equality       ::= Relational { ("==" | "!=") Relational }

Relational     ::= Additive { ("<" | "<=" | ">" | ">=") Additive }

Additive       ::= Multiplicative { ("+" | "-") Multiplicative }

Multiplicative ::= Unary { ("*" | "/" | "%") Unary }

Unary          ::= [ "-" | "!" ] Postfix

Postfix        ::= Primary { "(" [ Arguments ] ")" | "[" Expression "]" | "." Identifier }

Primary        ::= Literal | Identifier | "(" Expression ")" | ArrayLiteral

ArrayLiteral   ::= "{" [ Expression { "," Expression } ] "}"

Arguments      ::= Expression { "," Expression }
```

### 2.6 Типы

```
Type           ::= "int" | "float" | "bool" | "void" | "string"
                | Identifier
                | Type "*"
                | Type "[" [ Expression ] "]"
```

### 2.7 Приоритет операторов (от высшего к низшему)

| Приоритет | Операторы | Ассоциативность |
|-----------|-----------|-----------------|
| 1 (высший) | `()` `[]` `.` `->` | Слева направо |
| 2 | `-` (унарный) `!` | Справа налево |
| 3 | `*` `/` `%` | Слева направо |
| 4 | `+` `-` | Слева направо |
| 5 | `<` `<=` `>` `>=` | Слева направо |
| 6 | `==` `!=` | Слева направо |
| 7 | `&&` | Слева направо |
| 8 | `\|\|` | Слева направо |
| 9 (низший) | `=` `+=` `-=` `*=` `/=` | Справа налево |

## 3. Семантика

### 3.1 Система типов

#### Базовые типы

| Тип | Размер | Описание |
|-----|--------|----------|
| `int` | 32 бита | Знаковое целое |
| `float` | 64 бита | Число с плавающей точкой (IEEE 754 double) |
| `bool` | 1 бит | Булево значение (true/false) |
| `string` | 16 байт | Строковый литерал (указатель + длина) |
| `void` | — | Отсутствие значения |

#### Составные типы

| Тип | Размер | Описание |
|-----|--------|----------|
| `struct Name` | Сумма полей | Пользовательская структура |
| `T[]` | 8 байт (указатель) | Массив элементов типа T |
| `T*` | 8 байт | Указатель на тип T |

#### Совместимость типов

```
Правила присваивания (T target = S source):

1. T == S                            → OK
2. T == float, S == int              → OK (расширение)
3. T == int,  S == float             → ОШИБКА (сужение)
4. T == T[],  S == T*                → OK (array decay)
5. T == T*,   S == T[]               → OK
6. Все остальные комбинации          → ОШИБКА
```

### 3.2 Правила типизации выражений

#### Арифметические операторы

| Оператор | Типы операндов | Тип результата |
|----------|---------------|----------------|
| `+`, `-`, `*` | int × int | int |
| | int × float | float |
| | float × int | float |
| | float × float | float |
| `/`, `%` | int × int | int |
| | float × float | float |

#### Операторы сравнения

| Оператор | Типы операндов | Тип результата |
|----------|---------------|----------------|
| `==`, `!=` | Совместимые | bool |
| `<`, `<=`, `>`, `>=` | int × int | bool |
| | float × float | bool |

#### Логические операторы

| Оператор | Типы операндов | Тип результата |
|----------|---------------|----------------|
| `&&`, `\|\|` | bool × bool | bool |
| `!` | bool | bool |

#### Унарные операторы

| Оператор | Тип операнда | Тип результата |
|----------|-------------|----------------|
| `-` | int | int |
| `-` | float | float |
| `!` | bool | bool |

### 3.3 Области видимости

```
Глобальная область
├── Функция main
│   ├── Параметры main
│   └── Блок main
│       ├── Переменные блока
│       └── Вложенный блок
│           └── Переменные вложенного блока
├── Функция factorial
│   ├── Параметры factorial
│   └── Блок factorial
└── Структура Point
    └── Поля Point
```

**Правила:**
1. Имена в разных функциях независимы
2. Вложенные блоки видят переменные внешних блоков
3. Запрещено повторное объявление в одной области видимости
4. Параметры функций видны только внутри функции
5. Поля структур видны через оператор `.`

### 3.4 Семантические проверки

| Проверка | Код ошибки | Описание |
|----------|-----------|----------|
| Необъявленная переменная | E001 | Идентификатор не найден в текущей или внешних областях |
| Повторное объявление | E002 | Имя уже объявлено в текущей области |
| Несовместимость типов | E003 | Тип выражения не совместим с ожидаемым |
| Неверное количество аргументов | E004 | Количество аргументов не соответствует сигнатуре |
| Неверный тип аргумента | E005 | Тип аргумента не совместим с параметром |
| Неверный возвращаемый тип | E006 | Тип return не совместим с типом функции |
| Неверное условие | E007 | Условие в if/while/for должно быть bool |
| Использование до объявления | E008 | Переменная используется раньше объявления |
| Недопустимое присваивание | E009 | Левая часть не может быть целью присваивания |
| Недопустимая унарная операция | E010 | Оператор не применим к типу операнда |
| Недопустимая бинарная операция | E011 | Оператор не применим к типам операндов |
| Функция не найдена | E012 | Вызов не-функции или необъявленной функции |
| Структура не найдена | E013 | Имя структуры не найдено |
| Поле не найдено | E014 | Поле не существует в структуре |
| Неверный размер массива | E015 | Размер массива не соответствует инициализатору |
| Неверный индекс массива | E016 | Индекс должен быть типа int |
| Несоответствие extern | E017 | Объявление extern не соответствует использованию |

## 4. Модель памяти

### 4.1 Локальные переменные

- Размещаются на стеке
- Размер: int = 4 байта, float = 8 байт, bool = 1 байт, указатель = 8 байт
- Выравнивание: int на 4 байта, float/указатели на 8 байт

### 4.2 Массивы

- **Локальные массивы** выделяются в куче через `malloc`
- Размер: `количество_элементов × sizeof(тип)`
- Указатель на массив хранится на стеке (8 байт)
- Автоматическое освобождение через `free` при выходе из области видимости
- **Глобальные массивы** размещаются в секции `.data` или `.bss`

### 4.3 Стек

- Растёт вниз (от старших адресов к младшим)
- Выравнивание кадра стека: 16 байт
- Формат кадра:
```
[RBP + 16]  Аргументы на стеке (если > 6)
[RBP + 8]   Адрес возврата
[RBP]       Сохранённый RBP
[RBP - N]   Локальные переменные
```

### 4.4 Куча

- Используется для динамических массивов
- Функции: `malloc(size)`, `free(ptr)`
- Проверка `malloc` на `NULL` с вызовом `abort()` при отказе

## 5. ABI (System V AMD64)

### 5.1 Регистры для параметров

| Номер | Целые | Float |
|-------|-------|-------|
| 1 | RDI | XMM0 |
| 2 | RSI | XMM1 |
| 3 | RDX | XMM2 |
| 4 | RCX | XMM3 |
| 5 | R8 | XMM4 |
| 6 | R9 | XMM5 |
| 7+ | Стек | Стек |

### 5.2 Возвращаемое значение

- Целые: RAX (64 бита) или EAX (32 бита)
- Float: XMM0
- Структуры: через скрытый указатель в RDI

### 5.3 Сохранение регистров

- **Callee-saved:** RBX, R12-R15, RBP, RSP
- **Caller-saved:** RAX, RCX, RDX, RSI, RDI, R8-R11

### 5.4 Стек

- Выравнивание на 16 байт перед `call`
- Красная зона: 128 байт ниже RSP (не используется)

## 8. Отличия от C

| Особенность | C | MiniLang |
|-------------|---|----------|
| Объявление функции | `int foo(int x)` | `int foo(int x)` или `fn foo(x int) -> int` |
| Точка с запятой после struct | Обязательна | Обязательна |
| Массивы | На стеке или в куче | Всегда в куче (malloc) |
| Указатели | Явные `*` | Неявные для массивов |
| Присваивание полям struct | `p.x = 10` | Ограниченная поддержка |
| Оператор `++` | Есть | Нет (используйте `i = i + 1`) |
| Заголовочные файлы | `#include` | `extern` объявления |
| Препроцессор | Полный | Только `-E` (токены) |
| Оператор `->` | Для указателей на struct | Не поддерживается |
| Многомерные массивы | `int m[3][4]` | Не поддерживаются |
| `char` тип | 1 байт | Нет (используйте `int`) |
| `NULL` | Макрос | Нет (используйте `0`) |

## 9. Примеры программ

### 9.1 Факториал
```c
int factorial(int n) {
    if (n <= 1) { return 1; }
    return n * factorial(n - 1);
}
int main() { return factorial(5); }  // 120
```

### 9.2 Числа Фибоначчи
```c
int fib(int n) {
    if (n <= 1) { return n; }
    return fib(n - 1) + fib(n - 2);
}
int main() { return fib(10); }  // 55
```

### 9.3 QuickSort
```c
void swap(int a[], int i, int j) { int t=a[i]; a[i]=a[j]; a[j]=t; }
int part(int a[], int l, int h) {
    int p=a[h]; int i=l-1;
    for(int j=l;j<h;j=j+1){ if(a[j]<=p){i=i+1;swap(a,i,j);} }
    swap(a,i+1,h); return i+1;
}
void qs(int a[], int l, int h) {
    if(l<h){ int pi=part(a,l,h); qs(a,l,pi-1); qs(a,pi+1,h); }
}
int main() { int a[5]={5,3,1,4,2}; qs(a,0,4); return a[0]*100+a[4]; }  // 105
```

### 9.4 Бинарный поиск
```c
int bs(int a[], int t, int sz) {
    int l=0; int r=sz-1;
    while(l<=r){ int m=(l+r)/2; if(a[m]==t){return m;} if(a[m]<t){l=m+1;}else{r=m-1;} }
    return -1;
}
int main() { int a[5]={1,3,5,7,9}; return bs(a,7,5); }  // 3
```
