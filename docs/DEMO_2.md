## Часть 1: Демонстрация


Компилятор поддерживает 22 флага командной строки: -S, -c, -E, -O, --ast, --ir, и другие.

### Шаг 1: Компиляция QuickSort

```bash


./bin/compiler -O -v examples/demo_quicksort.src -o /tmp/qsort.asm
```

Скомпилируем быструю сортировку. Флаг -O включает оптимизации, -v показывает этапы.

### Шаг 2: Просмотр ассемблера

```bash
/tmp/qsort.asm
```

"В сгенерированном коде — прологи функций, работа со стеком, вызовы malloc/free для массивов, вычисление адресов элементов через GEP"

### Шаг 3: Сборка и запуск

```bash
nasm -f elf64 -o /tmp/qsort.o /tmp/qsort.asm
nasm -f elf64 -o /tmp/rt.o src/runtime/runtime.asm
gcc -no-pie -o /tmp/qsort /tmp/rt.o /tmp/qsort.o
/tmp/qsort
echo "Exit: $?"
101
```

"Ассемблируем nasm, линкуем с runtime, запускаем. Exit code 101 — это сумма первого и последнего элементов отсортированного массива."

### Шаг 4: Показ ошибок

```bash
$ cat > /tmp/err.src << 'EOF'
int main() {
    int x = "hello";
    return x;
}
EOF

$ ./bin/compiler check /tmp/err.src
```

### Шаг 5: IR и AST (15 сек)

```bash
$ ./bin/compiler --ir examples/demo_quicksort.src
$ ./bin/compiler --ast examples/demo_quicksort.src
```

"Можно посмотреть промежуточное представление и AST для отладки."

## Часть 2: Особенности и сложности (1 минута)

Ключевые особенности

```
 Полный pipeline компиляции (6 этапов)
 50+ типов токенов, 20+ узлов AST
 17 кодов ошибок + 3 предупреждения
 25 IR инструкций в SSA-форме
 9 оптимизационных проходов
 Динамические массивы (malloc/free)
 Внешние функции C (printf, malloc)
 System V AMD64 ABI (стек, регистры)
 80+ финальных тестов
```

Технические решения

| Проблема | Решение |
|----------|---------|
| Парсер: LL(1) грамматика, левая рекурсия | Рекурсивный спуск + синхронизация |
| Таблица символов: вложенные области | Иерархическая структура Scope |
| IR: SSA форма | Базовые блоки + PHI-узлы |
| Кодогенерация: выравнивание стека | AllocateVar с выравниванием на размер |
| Массивы: управление памятью | malloc/free с проверкой на NULL |
| Ошибки: каскадные ошибки | --max-errors + синхронизация |

### Устное выступление:

> "Ключевые технические решения: рекурсивный спуск для парсера с синхронизацией при ошибках, иерархическая таблица символов для областей видимости, SSA-форма IR для оптимизаций, и тщательное выравнивание стековых переменных согласно ABI. Массивы выделяются динамически через malloc с автоматической проверкой на NULL."
